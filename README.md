ZeroType 提示詞大全
這個資料夾收錄 ZeroType 的基礎系統提示詞與常見任務模板，適合拿來當作通用起點。
典型用法是把 SYSTEM.md 當作共用系統提示詞，再搭配其中一個 USER 或 USER-xx 提示詞，決定最後要輸出什麼結果。
這個資料夾適合什麼
建立 ZeroType 的基礎提示詞組合
處理中文語音轉文字稿的校正
產生日常聊天訊息、翻譯內容、Issue 草稿
把語音指令整理成可交給 ZeroType Agent 執行的任務
檔案用途
SYSTEM.md：共用系統提示詞。負責語音校正、安全邊界、上下文使用規則，以及常見語音辨識錯字對照表。
USER.md：只做最小幅度的語音校正與標點補齊，輸出繁體中文，不做翻譯、不延伸內容。
USER-01.朋友閒聊.md：把口語逐字稿整理成自然、像朋友聊天的繁中訊息，可加入少量表情與台灣口語感。
USER-02.撰寫貼文 (LINE).md：把逐字稿改寫成可直接傳送的 LINE 訊息，適合通知、邀約、說明近況等情境。
USER-03.哄老婆開心.md：把原始語句改寫成溫柔、親密、照顧情緒的伴侶對話訊息，適合修補情緒或表達關心。
USER-04.ZeroType Agent.md：把使用者的語音需求整理成明確任務，並透過固定快捷鍵與貼上流程轉交給 ZeroType Agent。
USER-05.中英雙語.md：先校正中文，再同時輸出通順中文與對應英文，適合需要對照版本的情境。
USER-06.英語回應.md：先校正中文，再只輸出自然英文，適合一般生活對話翻譯。
USER-07.印尼文翻譯助理.md：把中文逐字稿翻成印尼文，情境鎖定台灣雇主與印尼籍家庭幫傭或看護的日常溝通。
USER-08.撰寫 Issue.md：把口語描述整理成規格文件、問題說明或 GitHub Issue 草稿，適合 PM、工程師、設計協作。
USER-09.聽我指令.md：把語音內容改寫成完整文本內容，並保留部分工具互動能力，適合一般命令型使用方式。
使用建議
如果你只想修正逐字稿，不想讓模型自行發揮，優先使用 USER.md。
如果你要把內容改寫成可直接傳送或交付的成品，依情境選擇對應的 USER-xx 檔案。
如果你希望把語音需求轉交給其他代理或工作流程，使用 USER-04.ZeroType Agent.md 會比較合適。
